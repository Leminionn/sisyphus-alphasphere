# How to replace/update an existing asset (image, video, documents)

**Article ID:** 1500009498782
**Locale:** en-us
**Article URL:** https://support.optisigns.com/hc/en-us/articles/1500009498782-How-to-replace-update-an-existing-asset-image-video-documents
**Last Updated:** 2026-09-10T18:51:56+00:00
---

You can replace/change an existing asset (image, video or document) by hovering your mouse over the asset in your library, and click ... then click "Replace Asset". The replacement must be the same media type as the original (i.e. image for image, video for video).

|  |
| --- |
| **NOTE** |
| Replace Asset is only available on **directly uploaded assets** (images, videos, documents). This does not include created Apps. |

A window will pop up.  You can drag in the new file that you want to use.

Click Upload 1 File.

The new file will be uploaded and take place of the old one. This may take some time depending on the size of the asset.

Everywhere this asset is used (playlist, schedule, ScreenZones, etc.) it will be replaced with the new file.
